# Phase 1 数据模型

## 存储边界

正式数据默认存放于 `%LOCALAPPDATA%\LifeOS\data\` 下的 SQLite 数据库，具体路径由 Settings 提供并允许覆盖。测试使用临时目录和独立数据库。数据库模块负责 Engine、Session、连接检查与 Repository；UI 不直接访问数据库。

## 基础设置

Phase 1 需要 `app_settings` 表，支持设置的插入、查询和修改，并在进程重启后保留。具体列定义、类型、约束和数据库文件名由 C 的实现及初始 Alembic 迁移确定，合并前由 A 审查并更新本文；此处不预设尚未协商的数据格式。

结构演进通过 Alembic 迁移管理。迁移须在空数据库上验证，测试不得修改正式数据库。当前尚无可宣称完成的迁移或持久化验收结果。
