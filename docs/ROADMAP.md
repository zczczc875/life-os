## 下一轮优先级

1. **复核试用版交付**。在独立的 Windows x64 环境下载 v0.2.0，使用临时数据目录走完首次启动、旧库副本升级、通知导入、编辑、计划排序和重启持久化。记录 Windows 版本、EXE 校验值及实测结果。已有本机验证，第二台设备结果待补。
2. **完成 Phase 5 的最小提醒闭环**。先支持一个可配置的 Windows 到期提醒。用现有本机截止时间作为计算依据，为仅有日期的任务定义固定触发时刻。保存任务编辑和完成状态后，应重算或取消提醒。验收覆盖准时触发、重启后恢复、错过后补发一次、重复扫描不重复提醒，以及已完成任务不提醒。再扩展多档提前量、每日简报、托盘和开机启动。
3. **按实际试用反馈扩展计划和平台能力**。保留可解释的截止时间排序，优先复核重要性或工作量能否解决实际排序问题。平台接入先验证单个授权来源能进入统一收件箱，再扩展其他来源。
