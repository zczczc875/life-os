## 下一轮优先级

1. **复核第二台 Windows 设备**。在独立的 Windows x64 环境使用临时数据目录走完首次启动、旧库副本升级、通知导入、编辑、计划排序和重启持久化。试用版另验收 Windows 系统通知及补发去重。记录 Windows 版本、EXE 校验值和实测结果。
2. **验证后台提醒的使用需求**。复核 Windows 登录启动和多档提前提醒，根据试用反馈确定每日简报内容和触发时间。
3. **按实际试用反馈扩展计划和平台能力**。保留可解释的截止时间排序，优先复核重要性或工作量能否解决实际排序问题。平台接入先验证单个授权来源能进入统一收件箱，再扩展其他来源。
