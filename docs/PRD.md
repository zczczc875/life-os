# LifeOS Phase 1 产品需求

## 目标

在 Windows 上交付可启动、可测试、具备本地持久化基础的桌面工程，为后续将通知转化为可确认任务、提醒及规划提供基础。本阶段不是完整的任务产品。

## 本阶段范围

1. 主窗口显示 LifeOS 名称、版本、欢迎信息和数据库连接状态，可正常关闭。
2. 读取统一配置，数据目录可覆盖，初始化轮转日志。
3. 使用本地 SQLite、SQLAlchemy 和 Alembic 提供数据库连接、迁移及基础设置持久化；设置支持插入、查询、修改并在重启后保留。
4. 定义 LLM Provider 接口和可重复调用的 Mock，不请求真实模型服务。
5. 提供模块测试、集成测试、安装和运行说明，并记录验收结果。

不包括微信、企业微信或钉钉接入，真实云端 AI 调用，完整任务引擎和多设备同步。后续云端 AI 可能需要将选定内容发送给服务提供商，本地优先不意味着数据永远不离开本机。

## 验收

- Windows 环境中按 README 安装、迁移及运行 `python -m lifeos`；窗口启动，展示正确连接状态，并可退出。
- 默认数据位于 `%LOCALAPPDATA%\LifeOS\data\`，配置可覆盖；初始迁移和设置重启持久化通过。测试库独立于正式数据。
- 配置和轮转日志可用，Mock 符合接口预期；导入无副作用，日志无完整聊天内容或真实密钥。
- `pytest`、`ruff check .` 与 `ruff format --check .` 结果已记录；各分支审查整合，遗留问题和负责人明确。

这些是目标与验收条件，不代表功能已经实现或验收已经通过。实际测试结果见项目交付记录。
