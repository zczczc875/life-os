## 启动与测试

在源码工作目录先安装项目依赖，首次使用或更新结构后执行：

```cmd
python -m alembic upgrade head
python -m lifeos
```

默认数据库为 `%LOCALAPPDATA%\LifeOS\data\lifeos.sqlite3`；`LIFEOS_DATA_DIR` 可覆盖目录。迁移由用户显式执行，应用不会自动修改数据库结构。自动化检查使用 `python -m pytest -q`、`ruff check .` 和 `ruff format --check .`。
